# 🎲 Монополия Онлайн

> Браузерная версия классической настольной игры Монополия — полностью на русском языке, с ИИ-противниками и Санкт-Петербургскими улицами!

[![Play Now](https://img.shields.io/badge/▶%20Играть-GitHub%20Pages-7c3aed?style=for-the-badge)](https://20xmas24.github.io/monopoly-online/)

---

## 🕹️ Как играть

1. Откройте `index.html` в браузере (или через GitHub Pages)
2. Введите имя и выберите фишку
3. Выберите количество игроков (2-4)
4. Нажмите **«Начать игру»** — и вперёд!

## 🗺️ Улицы Санкт-Петербурга

Вместо классических Мэдисон и Бродвея — петербургские улицы:

- 🟫 **Коричневые**: Садовая, Лесная
- 🩵 **Голубые**: Проспект, Московская, Набережная
- 🩷 **Розовые**: Пушкинская, Невский, Лиговский
- 🟠 **Оранжевые**: Кронверкский, Литейный, Загородный
- 🔴 **Красные**: Гороховая, Апраксин
- 🟡 **Жёлтые**: Средний, Большой, Каменноостровский
- 🟢 **Зелёные**: Каменный остров, Рубинштейна, Правды

## 🛠️ Технологии

- **Pure HTML5 + CSS3 + JavaScript** — без фреймворков
- **Canvas API** — отрисовка игровой доски
- **Google Fonts** — Russo One + Nunito
- Один файл `index.html` (~60KB)
